  <Step>
    ## Load a Pre-trained Model (2 minutes)

    We'll start with Qwen 2.5 (3B) - a small but powerful model perfect for learning.

    <Callout title="For Non-Technical People">
      Loading a pre-trained model is like adopting a dog that already knows basic commands. We don't need to teach it language from scratch - it already understands English!
    </Callout>

    ```python
    # Load the model (3 billion parameters - small but capable!)
    model, tokenizer = FastLanguageModel.from_pretrained(
        model_name = "unsloth/Qwen2.5-3B-Instruct",
        max_seq_length = 2048,        # Maximum context length
        dtype = None,                  # Auto-detect best precision
        load_in_4bit = True,          # Use 4-bit quantization
    )

    # Enable LoRA (Low-Rank Adaptation) for efficient training
    model = FastLanguageModel.get_peft_model(
        model,
        r = 16,                                                      # LoRA rank
        target_modules = ["q_proj", "k_proj", "v_proj", "o_proj"], # Attention layers
        lora_alpha = 32,
        lora_dropout = 0,
        use_gradient_checkpointing = "unsloth",
    )

    print("✅ Model loaded successfully!")
    ```

    **Code Explanation:**
    - `load_in_4bit = True` - Compresses model to 25% size (8GB → 2GB)
    - `get_peft_model` - Sets up LoRA, which only trains 1% of parameters (faster!)
    - `r = 16` - Controls how many parameters to train

    <Callout title="First-Time Download" type="warn">
      The first time you run this, it downloads ~2GB of model weights (takes 3-5 minutes). Subsequent runs are instant!
    </Callout>
  </Step>

  <Step>
    ## Create Training Data (5 minutes)

    We'll create a simple dataset teaching the model to solve basic math problems.

    <Callout title="For Non-Technical People">
      We're giving the AI 10 practice problems like "What is 5 + 3?" The AI will try different answers, and we'll reward it when it gets them right!
    </Callout>

    ```python
    # Create 10 simple math problems
    training_data = [
        {"prompt": "What is 5 + 3?", "correct_answer": "8"},
        {"prompt": "What is 12 - 7?", "correct_answer": "5"},
        {"prompt": "What is 4 * 6?", "correct_answer": "24"},
        {"prompt": "What is 20 / 4?", "correct_answer": "5"},
        {"prompt": "What is 15 + 8?", "correct_answer": "23"},
        {"prompt": "What is 30 - 12?", "correct_answer": "18"},
        {"prompt": "What is 7 * 3?", "correct_answer": "21"},
        {"prompt": "What is 45 / 9?", "correct_answer": "5"},
        {"prompt": "What is 100 + 50?", "correct_answer": "150"},
        {"prompt": "What is 80 - 25?", "correct_answer": "55"},
    ]

    # Convert to Dataset format
    dataset = Dataset.from_list(training_data)
    print(f"✅ Created dataset with {len(training_data)} examples")
    ```

    <Callout title="Pro Tip" type="info">
      Start small! 10-50 examples are enough to see results. You can always add more later.
    </Callout>
  </Step>

  <Step>
    ## Define Your Reward Function (7 minutes)

    This is the brain of reinforcement learning! The reward function tells the model what's "good" and what's "bad".

    <Callout title="For Non-Technical People">
      A reward function is like a teacher grading homework. When the student writes "8" for "5 + 3", they get an A+ (high reward). When they write "banana", they get an F (negative reward).
    </Callout>

    ```python
    def reward_function(prompts, outputs, correct_answers):
        """
        Calculate rewards for each model output.

        Returns:
            List of reward scores (one per output)
        """
        rewards = []

        for output, correct in zip(outputs, correct_answers):
            # Extract just the number from model output
            numbers = []
            for word in output.split():
                try:
                    numbers.append(int(word))
                except:
                    continue

            # Calculate reward based on correctness
            if len(numbers) == 0:
                reward = -1.0  # No number found: BAD
            elif str(numbers[0]) == correct:
                reward = +3.0  # Correct answer: EXCELLENT!
            else:
                # Partial credit based on how close
                try:
                    distance = abs(int(correct) - numbers[0])
                    reward = max(-3.0, 1.0 - (distance / 10))
                except:
                    reward = -2.0

            rewards.append(reward)

        return rewards

    print("✅ Reward function defined!")
    ```

    ### Reward Examples:

    | Question | Model Answer | Correct | Reward |
    |----------|-------------|---------|--------|
    | What is 5 + 3? | "8" | "8" | +3.0 ✅ |
    | What is 5 + 3? | "7" | "8" | +0.9 📊 |
    | What is 5 + 3? | "I don't know" | "8" | -1.0 ❌ |
    | What is 5 + 3? | "100" | "8" | -3.0 ⚠️ |
  </Step>

  <Step>
    ## Train Your Model! (8 minutes)

    Now for the exciting part - let's train using GRPO (Group Relative Policy Optimization)!

    ```python
    # Configure training
    config = GRPOConfig(
        output_dir = "./grpo_output",
        num_train_epochs = 3,
        per_device_train_batch_size = 1,
        gradient_accumulation_steps = 4,
        num_generations = 8,           # Generate 8 answers per question
        learning_rate = 5e-6,
        temperature = 1.2,
    )

    # Create trainer
    trainer = GRPOTrainer(
        model = model,
        args = config,
        train_dataset = dataset,
        reward_function = reward_function,
        tokenizer = tokenizer,
    )

    # START TRAINING! 🚀
    print("🚀 Starting training...")
    trainer.train()
    print("✅ Training complete!")
    ```

    ### What happens during training:
    1. **Generation:** Model generates 8 different answers for each question
    2. **Evaluation:** Reward function scores all 8 answers
    3. **Learning:** Model adjusts to produce more high-reward answers
    4. **Repeat:** Process repeats for 3 epochs

    <Callout title="Training Time" type="warn">
      With 10 examples and 3 epochs, training takes about 5-8 minutes on a free T4 GPU. You'll see a progress bar.
    </Callout>

    ### What to watch during training:
    - **Steps 1-30:** Rewards near 0 or negative (model is exploring)
    - **Steps 30-60:** Small positive rewards appear (finding correct answers)
    - **Steps 60+:** Rewards increasing toward +3.0 (mastering the task!)
  </Step>
</Steps>
