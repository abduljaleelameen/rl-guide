## Choose Your Learning Path

Whether you're a complete beginner or an experienced ML engineer, we've designed three distinct learning paths tailored to your skill level and goals.

![Learning Paths Overview](/reinforcement-ai/18-learning-paths-overview.svg)

<Tabs items={['Beginner', 'Intermediate', 'Advanced']}>
  <Tab value="Beginner">
    ### Beginner Track

    **For:** Non-technical users, students, product managers
    **Time:** 2-3 hours
    **Prerequisites:** Basic understanding of AI concepts

    **You'll Learn:**
    - What is reinforcement learning (with real-world analogies)
    - How reward functions work (simple examples)
    - Your first RL model in 30 minutes (guided tutorial)
    - Basic concepts: rewards, agents, environments

    <Card href="/docs/reinforcement-ai/examples/example-1" title="Start Beginner Track">
      Begin with Example 1: Simple Sentiment Reward
    </Card>
  </Tab>

  <Tab value="Intermediate">
    ### Intermediate Track

    **For:** Developers, data scientists, ML practitioners
    **Time:** 4-6 hours
    **Prerequisites:** Python programming, basic ML knowledge

    **You'll Learn:**
    - Designing sophisticated reward functions
    - Multi-metric evaluation systems
    - Custom system prompts and templates
    - PPO vs GRPO: when to use which

    <Card href="/docs/reinforcement-ai/examples/example-4" title="Start Intermediate Track">
      Begin with Example 4: Multi-Metric Rewards
    </Card>
  </Tab>

  <Tab value="Advanced">
    ### Advanced Track

    **For:** ML engineers, researchers, production teams
    **Time:** 8-12 hours
    **Prerequisites:** Experience with LLM training, PyTorch

    **You'll Learn:**
    - vLLM integration for production speed
    - Domain mixing strategies (code + reasoning)
    - Memory optimization techniques (90% reduction)
    - Production deployment pipelines

    <Card href="/docs/reinforcement-ai/examples/example-6" title="Start Advanced Track">
      Begin with Example 6: vLLM Integration
    </Card>
  </Tab>
</Tabs>

## Not sure which path to choose?

<Cards>
  <Card title="Choose BEGINNER if:">
    - You're new to machine learning
    - You want to understand concepts first
    - You prefer analogies over math
  </Card>
  <Card title="Choose INTERMEDIATE if:">
    - You code in Python regularly
    - You've trained ML models before
    - You want hands-on examples
  </Card>
  <Card title="Choose ADVANCED if:">
    - You're deploying to production
    - You need performance optimization
