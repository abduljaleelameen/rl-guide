## The AI Learning "Cake" (Yann LeCun's Analogy)

Back in 2016, AI pioneer Yann LeCun used a brilliant analogy to explain the different types of machine learning. Think of training an AI like baking a cake:

![The Machine Learning Cake](/reinforcement-ai/05-cake-analogy.svg)

<Cards>
  <Card title="The Cake: Pre-training">
    **What:** Training on massive amounts of text data

    **Simple explanation:** The model reads the entire internet and learns patterns in language - grammar, facts, reasoning patterns

    **Technical:** Self-supervised learning on trillions of tokens, predicting the next word
  </Card>

  <Card title="The Icing: Fine-tuning (SFT)">
    **What:** Teaching the model to follow instructions

    **Simple explanation:** Showing the model examples of good conversations so it learns to be helpful

    **Technical:** Supervised fine-tuning on instruction-response pairs
  </Card>

  <Card title="The Cherry: Reinforcement Learning">
    **What:** Learning from feedback to improve quality

    **Simple explanation:** Human raters or AI judges score responses, and the model learns to produce better answers

    **Technical:** RLHF/DPO/GRPO to align model outputs with human preferences
  </Card>
</Cards>

![The Training Pipeline](/reinforcement-ai/06-training-pipeline.svg)

<Callout title="Fun Fact">
  Yann LeCun presented this cake analogy in September 2016 - nearly 10 years ago! It took until 2023-2024 for the industry to fully realize and implement these concepts at scale.
</Callout>

## Stage Details

### 1. Pre-training

The foundation layer where models learn general language understanding by predicting the next token across massive text corpora.

- **Data:** Web pages, books, code, conversations (trillions of tokens)
- **Objective:** Next-token prediction
- **Duration:** Weeks to months on thousands of GPUs
- **Cost:** Millions to tens of millions of dollars

### 2. Mid-training (Optional)

Domain-specific knowledge injection for specialized capabilities.

- **Data:** Math problems, code repositories, scientific papers
- **Objective:** Enhanced performance on specific domains
- **Used by:** Models targeting specialized use cases

### 3. Supervised Fine-Tuning (SFT)

Teaching the model to follow instructions and have conversations.

- **Data:** Instruction-response pairs (thousands to hundreds of thousands)
- **Objective:** Learn Q&A format, helpfulness, instruction-following
- **Duration:** Hours to days
- **Result:** Base model → Instruct model

### 4. Post-training (RLHF/DPO)

Alignment with human preferences and values.

- **Data:** Human preference comparisons
- **Objective:** Helpful, harmless, honest responses
- **Methods:** RLHF, DPO, GRPO
- **Result:** Aligned, safe assistant

### 5. RLVR (RL with Verifiable Rewards)

Advanced reasoning through verifiable task completion.

- **Data:** Math problems, coding challenges, logic puzzles
- **Objective:** Step-by-step reasoning and problem solving
- **Verification:** Automatic correctness checking
- **Result:** Reasoning model (O1/R1 level)
